Various '''Entities''' have different metadata fields and [[Minecraft Wiki:Projects/wiki.vg merge/Entity statuses|status codes]]. 

These are the valid codes for Minecraft Java Edition 1.21.4; for upcoming snapshots, see [[Minecraft Wiki:Projects/wiki.vg merge/Pre-release protocol#Entity Metadata|Pre-release protocol#Entity Metadata]].

This page is maintained semi-automatically using a work-in-progress script made by mat, so it should update fairly quickly to new Minecraft versions. Regardless, it's not recommended that you parse it programmatically. Instead, consider using Bixilon's [https://gitlab.bixilon.de/bixilon/pixlyzer PixLyzer] or [https://github.com/Pokechu22/Burger Burger] (or [https://github.com/mat-1/Burger mat's Burger fork], which the script for updating this page depends on).

== Entity Metadata Format ==

Note that entity metadata is a totally distinct concept from block metadata.  It is not required to send all metadata fields, or even any metadata fields, so long as the terminating entry is correctly sent.

Entity Metadata is an array of entries, each of which looks like the following:

 |-

=== Abstract Minecart ===

{{Metadata inherit|Abstract Minecart|inherits=Abstract Vehicle}}

{| class="wikitable"
 ! Index
 ! Type
 !style="width: 250px;" colspan="2"| Meaning
 ! Default
 |-
 | {{Metadata id|}}
 | {{Metadata type|VarInt}}
 |colspan="2"| Custom block state ID
 | 0
 |-
 | {{Metadata id|}}
 | {{Metadata type|VarInt}}
 |colspan="2"| Custom block Y position (in 16ths of a block)
 | 6
 |-
 | {{Metadata id|}}
 | {{Metadata type|Boolean}}
 |colspan="2"| Show custom block
 | false
|}

If show custom block is false, then each type of Minecart will render its own type of block with its own properties.  Note that one does ''not'' need to send these values for the metadata fields, as the client will automatically select them if show custom block is false.  They are only provided for reference to help with swapping out other blocks.

* Rideable Minecarts contain air (<code>minecraft:air</code>) and have a y position of 6
* Chest Minecarts contain chests facing north (<code>minecraft:chest[facing=north]</code>) and have a y position of 8
* Furnace Minecarts contain a normal furnace facing north when unpowered (<code>minecraft:furnace[facing=north]</code>) and a lit furnace facing north when powered (<code>minecraft:furnace[facing=north, lit=true]</code>) and have a y position of 6 in both cases
* Hopper Minecarts contain a hopper (<code>minecraft:hopper</code>) and have a y position of 1
* TNT Minecarts contain TNT (<code>minecraft:tnt</code>) and have a y position of 6
* Command block minecarts contain a Command Block (<code>minecraft:command_block</code>) and have a y position of 6
* Spawner Minecarts contain a spawner (<code>minecraft:spawner</code>) and have a y position of 6
